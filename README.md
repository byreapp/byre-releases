# Byre

Run PostgreSQL, MySQL and MongoDB side by side on your Mac, and browse any database in Studio.

**Website:** [byre.app](https://byre.app) · **Docs:** [byre.app/docs](https://byre.app/docs)

## Download

Get the latest version from [byre.app/download](https://byre.app/download) or from [Releases](https://github.com/byreapp/byre-releases/releases/latest).

- **Apple silicon:** `Byre_<version>_aarch64.dmg`
- **Intel:** `Byre_<version>_x64.dmg`

Byre updates itself. It checks for a new version at launch, and you can check any time in **Settings → About → Check for updates**.

## Report a bug or request a feature

[Open an issue](https://github.com/byreapp/byre-releases/issues/new/choose). Please search [existing issues](https://github.com/byreapp/byre-releases/issues?q=is%3Aissue) first.

For bugs, include your version info. In Byre, open **Settings → About → Copy version info** and paste it into the issue.

## Security

Please don't report security problems in a public issue. Use [private vulnerability reporting](https://github.com/byreapp/byre-releases/security/advisories/new) instead.
