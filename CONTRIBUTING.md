# Contributing

Byre is commercial software and its source code is not public, so this repository doesn't take
code contributions or pull requests. Bug reports and ideas are very welcome.

## Filing an issue

1. Search [existing issues](https://github.com/byreapp/byre-releases/issues?q=is%3Aissue) first.
   If yours is there, add a thumbs-up reaction or a comment with new details instead of opening a duplicate.
2. [Open an issue](https://github.com/byreapp/byre-releases/issues/new/choose) and choose
   **Bug report** or **Feature request**.
3. For bugs, paste your version info (in Byre, **Settings → About → Copy version info**), the
   steps to reproduce, and any error messages or screenshots.

Remove passwords, connection strings and other secrets before posting.

For questions about using Byre, check the [docs](https://byre.app/docs) first. Security problems
go through [private vulnerability reporting](SECURITY.md), never a public issue.
