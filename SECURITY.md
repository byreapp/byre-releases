# Security

Please don't report security problems in a public issue. Use
[private vulnerability reporting](https://github.com/byreapp/byre-releases/security/advisories/new)
instead.

Include what you found, how to reproduce it, and your version info (in Byre, open
**Settings → About → Copy version info**). We'll reply in the advisory.

## Supported versions

Only the [latest release](https://github.com/byreapp/byre-releases/releases/latest) gets
security fixes. Byre updates itself, so staying on the latest version is the best protection.
